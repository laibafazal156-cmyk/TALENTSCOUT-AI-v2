# TalentScout AI v2

An AI-powered platform that helps candidates analyze their CVs, verify certificates, and discover matching opportunities such as jobs and internships.

## Features

- **CV Analysis and Recommendations**: analyzes CV content and suggests improvements
- **CV Matching and Profile Comparison**: compares candidate profiles with opportunities
- **Certificate Verification**: validates uploaded certificates
- **Opportunity Collection and Extraction**: gathers opportunities and extracts key details using AI
- **Duplicate Resolution and Deadline Tracking**: removes duplicate listings and tracks deadlines
- **User Authentication**: secure login and profile management

## Tech Stack

- Python
- Streamlit

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Copy `.env.example` to `.env` and add your own API keys.
